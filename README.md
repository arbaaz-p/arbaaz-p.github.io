# Arbaaz Pathan Portfolio

A lightweight static portfolio for GitHub Pages.

## Local preview

```bash
python3 -m http.server 4173 --directory portfolio-site
```

Open `http://localhost:4173`.

## Publish

Publish these files in a public GitHub repository named `arbaaz-p.github.io`. GitHub Pages will serve the site at `https://arbaaz-p.github.io`.

The portfolio links to separate repositories for the file-integrity monitor, Java concurrent queue, image-processing lab, and checkers game. A downloadable résumé is intentionally omitted until the highlighted Nike placeholders in the current draft are replaced.
